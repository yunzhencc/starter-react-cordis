# UI Theme Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an in-process Cordis UI theme plugin with system/light/dark selection, persisted content font size, and a Settings-contributed appearance panel.

**Architecture:** `core/runtime` gains only typed service and Settings-item contributions. `@yunzhen/cordis-ui-theme` hides storage, media-query handling, DOM updates, CSS injection, and its React appearance panel behind `ThemeRuntime` and one Cordis plugin. The Settings feature renders all registered items; the web bundle explicitly composes the built-in theme plugin.

**Tech Stack:** TypeScript 6, React 19, React Router 7, Vite 8, Vitest 4, jsdom, `@deepseek-ai/cordis` 4.

**Spec:** `docs/superpowers/specs/2026-09-01-ui-theme-design.md`

## Global Constraints

- Use `@yunzhen/cordis-*` package names and only workspace dependencies already needed by the feature.
- Keep the app browser-only: `localStorage`, `matchMedia`, and DOM state; no Node Settings service or remote sync.
- Persist only `@yunzhen/cordis-ui-theme:preference` and `@yunzhen/cordis-ui-theme:font-size`.
- Support `system | light | dark`; default to `system`; default content font size to `16`, clamped to `12–20`.
- Use native CSS Modules plus static global Token CSS. Do not add Sass, Less, Tailwind, CSS-in-JS, an event bus, or a module loader.
- Preserve static, startup-time route assembly and exclude custom theme registration, token overrides, and third-party plugin support.

- [ ] **Step 4: Add the no-flash bootstrap script**

  Insert this inline script before `<div id="root">` in `apps/web/index.html`. It must not create listeners or write storage:

  ```html
  <script>
    (() => {
      const preferenceKey = '@yunzhen/cordis-ui-theme:preference'
      const fontSizeKey = '@yunzhen/cordis-ui-theme:font-size'
      let preference = 'system'
      let fontSize = 16
      try {
        const savedPreference = localStorage.getItem(preferenceKey)
        if (savedPreference === 'light' || savedPreference === 'dark' || savedPreference === 'system') preference = savedPreference
        const savedFontSize = Number(localStorage.getItem(fontSizeKey))
        if (Number.isFinite(savedFontSize)) fontSize = Math.min(20, Math.max(12, savedFontSize))
      } catch {}
      const dark = preference === 'dark' || (preference === 'system' && matchMedia('(prefers-color-scheme: dark)').matches)
      const theme = dark ? 'dark' : 'light'
      document.documentElement.dataset.theme = theme
      document.documentElement.style.colorScheme = theme
      document.documentElement.style.setProperty('--app-content-font-size', `${fontSize}px`)
    })()
  </script>
  ```
